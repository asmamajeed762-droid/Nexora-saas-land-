# NEXORA  SaaS Landing Page

A modern and responsive SaaS landing page built with React and Tailwind CSS. Nexora features a clean design, engaging sections, and a user-friendly layout.

# Features

- Modern and responsive design
- Hero section with call-to-action buttons
- Features and benefits section
- Customer logos section
- Testimonials section
- Pricing plans
- Contact form UI
- Easy-to-customize content and images

# Technologies Used

- HTML5
- React.js
- Tailwind CSS
- JavaScript (ES6+)
- CDN Integration

# Project Structure

NEXORA/
│
├── index.html
├── images/
└── assets/

# How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click "index.html" to open it in your browser.
4. An internet connection is required because React and Tailwind CSS load from CDNs.

# Customization

- Edit Text: Open "index.html" and find the "CONTENT" section.
- Change Images: Replace files inside the "images/" folder while keeping their original filenames.
- Update Content: Customize navigation links, features, pricing plans, and testimonials.

# Important Notes

- Customer logos, testimonial names, companies, and photos are placeholders.
- Replace placeholder content with genuine information before publishing.
- The contact form is currently a demo and does not send emails. Connect it to a backend or form service to enable submissions.
