NEXORA LANDING PAGE
===================
1. Open index.html in any browser (double-click). Needs internet once, because React and Tailwind load from a CDN.
2. Edit text: open index.html in a text editor and look at the CONTENT section (navLinks, perks, plans, quotes).
3. Change pictures: replace the files inside the images/ folder, keeping the same file names.
4. Demo content: the logos (Google, Microsoft, Slack, Figma, Notion, Zoom), the testimonial names, companies and photos are placeholders.
   Replace them with real ones, and only show real customers or endorsements that are genuine.
5. The contact form is a demo and does not send email. Connect it to your backend or a form service in the submit function.
6. To publish: upload this whole folder (index.html + images/) to any static host such as Netlify, Vercel or GitHub Pages.
